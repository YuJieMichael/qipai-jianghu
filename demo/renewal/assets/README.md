2026-10-30 使用内置 imagegen 生成，未使用六六英雄的纹理、角色或代码。图片已保存到本项目，运行时无远程图像依赖。

- `forest-path.png`：1024×1536，明亮青绿武侠石径，竖向纵深战斗背景。
- `characters.png`：2172×724，初版透明四列图集，保留供回退。
- `characters-polished-v2.png`：2172×724，基于初版精修的透明四列图集，作为动作图集加载失败时的回退。依次为青巾侠客、刀客、弩手、山门守将；绘制时读取透明边界裁切。
- `characters-actions-v1.png`：1254×1254、RGBA 透明、四列四行原创动作图集，当前用于战斗。列依次为青巾侠客、刀客、弩手、山门守将；行依次为待机、攻击、受击、倒下。每格是不同的肢体绘画，保留武器、衣甲和面部风格。读取透明边界后按待机身体比例缩放，底部统一锚定；倒下姿态保持自然较矮的高度，不拉长。减少动态模式仍显示动作姿态，同时关闭位移、缩放、镜头与倒下渐隐。
- `rain-temple-v1.png`：1024×1536，原创暮雨山门、湿石径与黄昏灯笼场景，第二章使用；加载失败回退青岚石径。

动作图集的生成结果留有不等宽透明沟槽，因此使用明确的源格边界，不能直接按四等分切片。X 边界为 `[0, 350, 640, 935, 1254]`，Y 边界为 `[0, 415, 690, 975, 1254]`；每格有至少 33 像素的有意义横向透明边距及 43 像素的纵向边距（alpha > 24 统计）。绘制前仅扫描一次 alpha，保留原 PNG；每列以待机裁切高度为统一比例、以脚底为固定基线。三个及更多敌人按该列所有姿态的最大宽度统一限宽，切换姿态不会变更目标中心。

渲染映射：普通 `attack` 的来源画攻击行，目标在命中时画受击行；`hurt` 的敌方来源画攻击行、正伤害的目标画受击行；`sword`/`flame` 释放时采用同一映射；`death` 的目标画倒下行，事件结束后隐藏。`charge` 只画待机、局部蓄气细环和层数文字；`intent`/`phase` 只画对应目标的短文字。事件快照仍在该事件完成后提交。
