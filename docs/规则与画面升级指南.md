# 规则与画面升级指南

入口为 `demo/`。在源码目录执行 `node server/start.mjs`，访问终端显示的本地地址。需要 Node.js 22+，没有新增依赖。

## 这次接入的规则

- 强化采用累计系数表；兵装同时显示保存等级、生效等级、装备上限和下一级装备平值。默认素、良、珍、逸四档基础上限为 +10、+14、+18、+20，每阶品质增加 4，最终仍受全局 +20 限制。换低上限装备不会丢失槽位等级。
- 品质工坊展示装备平值、品质百分比及装备合计。品质百分比只放大装备部分，其他系统继续单独相加。默认一阶攻击 +5%，二阶气血 +5%，三阶再加攻击和减伤各 +5%。
- 成长先筛选禁选、前置和满级项，再抽稀有度、流派池和具体条目。可用的本门绑定保底，候选不重复；跨品质补足会显示说明并保留条目真实品质。一至两张候选照常选择，零张候选自动继续。
- 已出现的候选随旅程保存，重新载入不会重抽。已开始的旅程保留出征时配置，修改门庭后要新出征才生效。

## 自己调整

进入「可视化创作」，选「强化与品质规则」或「成长规则」，再点「打开条目」。编辑后用「校验并应用此条目」保存。强度、上限、品质百分比、池与条目权重、章节倾向都可编辑；权重是满足条件后相对比较，不是全局出现概率。

先在「JSON与备份」导出档案和内容文本。旧自订内容缺少新 optional 规则时继续旧算法，整个 expansion 缺失也按旧默认补全。想主动采用新规则，可点「恢复默认内容配置」，但会替换原自订内容；个人资源保留，自订条目不兼容时会拒绝恢复。自订稀有度 ID 的强化上限按 rank 0、1、2、3 以上映射四档，标准 ID 优先采用自己的上限。

## 画面与操作

战斗和成长界面参考公开截图的信息层次：厚实骰面、红绿血条、醒目出招按钮和品质卡框，继续使用原创武侠角色与场景。自动掷骰、选中要换的骰子后批量重掷、手动出招保持不变；演出仍可切换速度、跳过、减少动态。

本轮未重制全部角色动画、场景和图标，也不表示已经达到参考游戏全部画面完成度。参考 APK 未实机运行，尚未确认的牌型倍率调用未接入；当前使用原创数值，不是原表移植。

源码入口：`demo/gear-rules.mjs` 管理强化与品质，`demo/growth-pools.mjs` 管理成长池，`demo/expansion-content.mjs` 管理默认参数，`demo/ui.mjs` 与 `demo/style.css` 管理战斗界面。完整测试命令为 `node --test tests/demo-*.test.mjs`。
