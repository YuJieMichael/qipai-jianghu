# 竹林演出与手机界面指南

这一轮集中完善夜雨竹林到山门首领的演出，沿用原创武侠剪纸画风。没有新增玩法或改变战斗强度。

## 角色与交锋

主角、近战、弓手、持盾敌人、精英和首领使用不同轮廓、武器与动作。准备、释放、受击、收招和倒地分段呈现，脚下保持落地；法杖和锤采用双手握持，精英与首领的长兵器调整为竖直举刃。衣甲、护膝、披风和兵器增加分层细节。死亡按真实事件顺序播放，结束后保持倒地。

## 流派与场景

剑气使用曲线路径和命中斩痕，万剑归宗先聚阵再发射；附毒为飞针，持续毒伤为体表蚀骨纹，毒爆具有地池与爆散；金刚护盾、挡击与反震分别表现。特效跟随真实目标，伤害数字增加暗底和描边。

竹林增加远近竹影、低亮月光、低雾、池面倒影和雨圈。命中时镜头只有轻微跟焦和缩放，随后归位；减少动态会关闭镜头运动、闪光和冲刺，保留必要的局部提示。演出仍有 1×、2×和跳过，开战自动掷骰，出招由玩家决定。

## 手机操作

战场、敌方目标、我方气血、五骰与出招优先排列。「完整推演」和「行囊与行装」默认折叠，点击标题可展开，键盘也可使用 Tab、Enter 和空格。选骰、择敌及下一回合保留开合状态；换战斗重新收起。

完整推演显示技能、毒伤、护盾和敌方回应。演出中仍可查看本次出招前推演，并有明确标识；实际结果看「上一回合战报」。行囊中保留药品、配装和已习得路线。屏幕较短、指引展开或敌方说明较长时仍可自然滚动。

360×800 的无指引场景实测：单敌和双敌出招按钮底部为 777 像素，第九节点三敌布局样例为 795 像素。三敌为真实关卡数据的固定布局预览，不代表从第一关手动打到该节点；独立规则模拟负责完整路线检查。

## 用手机打开

手机浏览器支持触屏操作，无需安装客户端。电脑上的 `127.0.0.1` 不能直接拿到手机使用。手机和电脑连接同一 Wi‑Fi 后，可在源码目录另开终端运行：

```sh
HOST=0.0.0.0 PORT=8770 node server/start.mjs
```

然后在手机访问 `http://电脑的局域网IP:8770/demo/`，IP 可在电脑的 Wi‑Fi 网络设置中查看。该命令是手动启用同网访问的方式，本轮没有执行它；当前预览仍在原本的电脑本地地址。无需替换正在使用的 8768 服务。

手机与电脑的本地存档分开；需要沿用进度时，在「JSON与备份」导出档案后导入手机，或使用账号的手动同步。进行中的旅程不包含在档案导出内。长期从外网打开需要另行部署网页。

## 自己修改

| 文件 | 用途 |
| --- | --- |
| `demo/actors.mjs` | 角色几何、装备纹饰、握持和倒地绘制 |
| `demo/choreography.mjs` | 动作阶段、姿态、演出时间与减动态 |
| `demo/scene.mjs` | 角色与特效顺序、事件生命周期、数字层 |
| `demo/scene-effects.mjs` | 流派轨迹、目标定位与轻微镜头跟焦 |
| `demo/scene-atmosphere.mjs` | 竹影、月光、雾气、水纹 |
| `demo/audio.mjs` | 本地合成音效 |
| `demo/ui.mjs`、`demo/style.css` | 战斗信息、原生折叠和手机间距 |

这是一轮基于现有 Canvas 角色的完善，不是全部角色贴图、骨骼动画和七章场景的重新制作。数值、RNG、掉落、存档格式、选中要换的骰子及手动出招均保留。
