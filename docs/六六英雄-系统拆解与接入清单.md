## 证据怎么读

- **确证：** 在保留代码中读到具体处理器、状态变化、调用或数据字段；是静态确证，不是运行录像或账号实测。
- **推断：** 从确证机制提出的可离线改编方案；不能当作原游戏的精确规则。
- **未知：** 没解码的表值、服务器返回、实际投放、上线状态、可达性或本轮未追完的调用。
- **原创接入：** 本项目自己编写的规则、数值、美术和实现。写「简化」表示只接入了其中一部分；写「未接」表示不能按同款功能宣传。

参考文件保留在工作目录 `work/66hero/`；下表路径以其下的 `readable/` 为根，`.js.txt` 是便于阅读的模块显示。`module-index.json` 将模块名、原始切片、哈希与显示文件对应；它记录切片提取没有执行模块。更细的英文调查台账为 `work/reference-expansion-inventory.md`。

已保留的独立数据解码只覆盖 **constCommon、diceHand 两个表切片**，见 `asset-audit/config-facts.json`；不是全部 1680 表都已解码。该记录所指 APK SHA-256 为 `27a1a3ff5f4368caa8b2c96744ae9972373a59447a4d16b62b831464bbea5cc9`，提取证据 ID 为 `ev_e0feda1f782c2a4446e2a6ebaada3790bec135b06d9f79d756eb5efcfa78e92f`。其余系统的实际物品数量、中文名称、价格、概率、升级曲线和最终伤害值大多未知。

## 与原版七派玩法合并的原创内容

门派、十二武学、九种物理面刻印、六武魂、称号、修炼／经脉、三位关系人物、赠礼／收徒／指导、采集与炼制，是本项目的本地玩法扩展；不能仅因参考有相似模块名就说成参考确证机制。

本地论剑、本地世界首领、四轮大会、三段押镖、两段悬赏、塔层持久进度、八室秘境均已有本地路线和结算入口，名称下的规则是原创离线设计。本地世界首领生命只在当前浏览器档案中保存，没有其他玩家参与。

## 当前接入的共同边界

- 配装、规则和路线于新出征生成快照；回门庭保留旧旅程，新出征会放弃旧局。药品先记局内消耗，终局／放弃结算后入档。
- 正常出征使用递增数字 `runId`，`settledRunIds` 防重复发奖。这是本地存档一致性规则，不能提供服务端反作弊或账号安全保证。
- 内容集中在 `demo/content.mjs`，档案动作在 `profile.mjs`，路线在 `adventures.mjs`，交互在 `main.mjs`／`hub-ui.mjs`；修改工具可导出、校验与应用 JSON。详细教程见《七派江湖-全系统玩法与修改指南》。
- 服务器支付、广告、账号同步、真实好友／聊天／公会、跨玩家协作、全球排行榜和直播活动日程没有接入。不能用离线敌人或本机状态冒充这些服务。

调查全程只读取保留模块与既有解析结果，没有运行参考 APK／模块，没有复制参考源代码或美术进产品。未恢复的表与运行行为继续标为未知。这份交付是可修改的原创离线工作台，**不是完整同款商业游戏**。
