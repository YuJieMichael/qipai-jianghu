# 七派江湖 · 全系统本地可改版

入口为仓库中的 `demo/`。这是在夜雨竹林示范基础上扩展的原创江湖工坊：先配装、改骰，再以剑气、毒针或金刚传承出征。原版首页 `index.html` 是另一套玩法，存档分开。完整入口与最新规则见 [深度系统与联机指南](../docs/深度系统与联机指南.md)。

## 启动

在源码包根目录运行：

```sh
node server/start.mjs
```

需要 Node.js 22+，浏览器打开终端显示的 <http://127.0.0.1:8768/demo/>。ES modules 需要 HTTP，不能直接双击 `demo/index.html`。不需构建或安装依赖；停止服务按 Ctrl+C。Python 静态服务和 GitHub Pages 可玩离线系统，账号、帮会和真人对战需要 Node 服务。

## 先玩一局

1. 向下滚动到「江湖门庭」，查看兵装、骰匣、武学和奇珍。
2. 「出征」选择传承、玩法和章节，点击「按当前配装出征」。
3. 开战和下一回合自动掷骰；点击需要更换的骰子，再点「重掷」。未选中的保留。
4. 选敌人、看完整推演，自己点击「出招」。自动掷骰不等于自动攻击。
5. 成长时先选武学，再选绑定骰并确认；路线精进可直接确认。Esc 返回重选。

快捷键：1–5 选择要换的骰子，R 重掷，空格执行当前主操作。焦点位于输入框、按钮或下拉框时保留原生键盘行为。顶部可静音、减少动态效果、回门庭或暂离。

七章常规路线具有独立敌群、布局与事件顺序，实际场景覆盖竹林、破庙、山门、沙漠、湖桥、墓穴和雪峰。其他模式保留专属路线并叠加章节与模式倍率。「出征」里的本地论剑不匹配真人，本地世界首领的生命仅在这台浏览器里累计；真人对战使用单独的「账号与论剑」入口。

剑强化顺子；法杖在两对及以上对存活敌人群攻；锤在三条及以上增加护盾并破势。门派切换会把五骰点数重置为本门默认面，之后可在骰匣重新修改。

## 存档、换装与结算

- 兵装、天赋、骰匣、内容配置在**新出征**时生成快照。回门庭改装后继续旧旅程，旧局保持原配装与路线。
- 「门庭」会保留当前旅程；「继续已保存旅途」恢复它。开始新出征或再入江湖会放弃未完成旧局：扣已用药品，不给放弃奖励。
- 药品先消耗本局行囊，胜负或放弃结算时才扣／合并门庭库存。局内购买的药品也随最终行囊结算。
- 正常门庭出征使用递增数字 `runId`；档案记录已结算编号，防止重复恢复或渲染再次领奖。不要手改这些编号。
- 三星章节才可扫荡。默认三星条件为通关、剩余气血至少 40%、累计交锋不超过 18 回合；参数可改。
- 离线所得按本机时间、完整小时领取，默认封顶 12 小时；时间倒退不产生收益。累计任务奖励一次领取；另有按 UTC 换日、周一 UTC 换周的日周任务。

自动存档使用同一浏览器、同一地址和端口的 localStorage。原版键 `qipai-jianghu-v1` 保留；本版档案键为 `qipai-bamboo-profile-v1`，旅程键为 `qipai-bamboo-demo-v1`，设置另存。旧示范旅程会校验并迁移到内部 v3。

## 不改代码也能改内容

1. 进入「JSON与备份」，先点「将档案写入文本」，复制整个文本框保存为 `档案备份.json`。
2. 点「将内容配置写入文本」，复制整个文本框保存为 `内容备份.json`。导出写入文本框，不会自动下载文件。
3. 在完整内容 JSON 中改显示 `name`、已有 `effects` 数字、`cost`／`reward`、章节 `hpScale`／`attackScale`、模式 `turnLimit` 或 `economy.offlineHours`。
4. 粘贴完整 JSON，点「校验并应用内容」。查看反馈；失败时旧配置保留。
5. 新出征检查变化。当前旅程快照不会因导入而改变。

`turnLimit` 必须是 1..1000 整数；`offlineHours` 默认 12，可设为 1..100 整数。资源成本／奖励用非负整数，倍率为正数。保持 `version: 1`、现有 ID、引用和固定枚举；特别不要增删槽位、材质、装饰、刻印、模式，或自造武器种类／触发关键字。改说明文字不会改变固定材质或装饰的程序行为。

内容 JSON 是规则目录；档案 JSON 是个人资源、装备实例、等级、领奖记录及内容覆盖。两者不能互换。档案导入按钮为「校验并导入档案」；档案导出不包含进行中的旅程，不能代替旅程备份。需要恢复规则时使用「恢复默认内容配置」，个人资源不会随之重置；档案还引用自订条目时会拒绝不兼容恢复。「领取测试补给」用于创作试配。

## 参考边界

参考拆解已完成 Android 1.4.2 包内 1,680 张配置切片的解码与结构核查，区分确证、推断和未知；没有执行参考 APK，也没有复制参考代码或美术。已确认的结构使用原创参数接入；牌型倍率的活动调用仍未确认，暂不调整。装备、套装、天赋、路线与数值使用原创实现，部分采用简化规则。Node 服务已提供账号、手动档案同步、帮会和双人对战；服务器支付／广告、全球跨服排名未接入，也未部署公网服务。这不表示参考全部系统已复刻。详见 [配置核查记录](../docs/六六英雄-全量配置解码与规则核查.md)。

## 战斗演出与战报

顶部演出按钮切换1×/2×；结算中可跳过当前整轮演出，结果和奖励不变。最新一轮战报支持展开查看实际伤害、气血与逐招事件，暂存于当前页面，不写入战斗或账号档案。减少动态设置继续覆盖摄像机、闪光和骰子落定动画。新版战斗采用明亮立体骰面、红绿血条和蓝金出招按钮，成长卡按真实品质显示卡框；[规则与画面升级指南](../docs/规则与画面升级指南.md) 提供调整入口与兼容说明。

夜雨竹林演出进一步完善了角色落地、双手武器、死亡、剑阵、附毒与毒爆、金刚反震、月光低雾和水纹。手机优先显示核心操作，完整推演与行囊改为可展开面板；演出中查看的是明确标识的出招前推演，真实结果见战报。具体操作与源码入口见 [竹林演出与手机界面指南](../docs/竹林演出与手机界面指南.md)。

## 强化、品质与成长候选

默认内容启用累计强化表和装备上限。兵装面板同时显示槽位保存等级、当前生效等级、当前上限及下一级装备平值。换成上限较低的装备只限制生效等级，不降低已保存等级；换回后恢复。品质工坊分别显示装备平值、品质百分比和装备合计，品质百分比只作用于装备属性，不放大天赋、套装和其他系统。

局内成长按稀有度、流派池、具体招式逐层抽取，先过滤禁选、前置和满级项，再按权重选择且不重复。可用的本门骰绑定保底；数量不足时回退其他稀有度，并保留招式真实品质。自订配置只有一两项可用时显示实际数量；完全没有候选时自动继续行路。存档保留已出现的候选，刷新页面不会重抽。

「创作台」可编辑强化累计系数、稀有度上限、品质百分比、流派池与招式权重、章节倾向。新默认配置启用这些规则；旧自订配置缺少 `gear.progression` 或 `rogue.selection` 时保留旧规则，已有旅程继续使用出征时的规则快照。使用「恢复默认内容配置」会主动启用当前默认内容。
