# 夜雨竹林·破山门：首版验证记录

验证日期：2026-10-29。开发分支：`feat/bamboo-demo`。

## 已交付体验

首页新增独立示范入口，无需创建角色。雨夜竹林、残灯破庙、风起山门三个场景串成九节点路线，包含五次成长、奇遇、营火、首领和胜负结算。原版游戏及 `qipai-jianghu-v1` 存档保持兼容。

主角和敌人使用原创 Canvas 绘制，包含待机、起手、位移、命中、受击及死亡表现。剑气、毒针、护盾反击使用不同轨迹、颜色与合成音效。提供静音和减少动态效果，尊重首次进入时的系统动态偏好。

剑气的万剑归宗、毒针的百毒归心、金刚的不动明王均在第三次本门成长解锁。首领半血召援，援军从下一回合开始行动；普通攻击和蓄力重击交替，重击重新生成架势，可破势中断。

## 浏览器实际交互

使用浏览器界面点击、读取真实骰盘、锁定与重掷、选择目标和成长，完成以下路线；未通过修改浏览器隐藏游戏状态跳过战斗。

| 最终版本，种子 2 | 结果 | 交锋回合 | 总伤害 | 击败敌人 |
|---|---|---:|---:|---:|
| 剑气 | 通关 | 16 | 860 | 11 |
| 毒针 | 通关 | 18 | 860 | 11 |
| 金刚 | 通关 | 28 | 860 | 11 |

剑气实际试玩在奇遇选择了治疗，因此与模拟策略的回合数不同。三条路线均选择本门成长并获得质变。另实测一次失败结算和重新开始。最终页面控制台未捕获 warning/error。

实测在破庙掷骰后刷新并继续，骰子标签、生命和回合保持一致；金刚路线暂离返回原版首页后，使用浏览器返回并继续，页面可操作且成长阶段气血保持一致。设置开关在界面可用，减少动态效果下完整通关。声音通过手势解锁与 API 生命周期检查；未进行跨设备听感验收。

通过同源 iframe 分别按 360px 和 1280px 内容宽度检查排版，并保存手机战斗与桌面开场截图。360px 下五骰、气血和敌人卡片均在横向宽度内；长内容允许纵向滚动。设置、暂离、继续按钮最小目标为 44px。

开发过程中发现普通预览服务器的资源缓存保留了旧模块，最终三条路线使用独立无缓存预览端口复测。固定种子地址 `/demo/?seed=2` 的初掷为 `[2,3,2,5,5]`，已与纯规则输出核对。

## 审查与交付边界

已完成模型、规则、成长/存档和表现/界面的任务审查，以及一次整体代码审查；提出的具体问题均修复并通过复审。实际试玩后补充的种子解析、奇遇数值及气血信息也已单独复审。

本次完成的是原创浏览器示范关卡。商业游戏级美术资产、逐设备性能/听感验收及大范围真人平衡测试仍属于后续打磨。8–12 分钟是设计目标，当前没有完成排除自动化和调试停顿的真人计时验收，不能将自动化耗时当作该目标的证明。

开发成果保存在独立分支；线上正式版本未发布。启动方式见 README，整个仓库可直接部署到 GitHub Pages，无构建步骤。
