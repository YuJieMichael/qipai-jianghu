# 七派江湖

一款在浏览器里直接玩的武侠网页游戏，向十几年前的页游《武侠风云》致敬。整个游戏只有一个 `index.html` 文件，不需要安装，不需要服务器。

**在线试玩：** https://yujiemichael.github.io/qipai-jianghu/

## 玩法

- **七大门派**：少林、武当、峨嵋、丐帮、明教、唐门、天山，各有 4 招门派武学和 1 招秘传绝学。
- **江湖与主线剧情**：七个区域、七章故事。七次抉择决定侠义、霸道、中庸三种结局。
- **通天塔**：无尽爬塔，层与层之间气血不回满，每 3 层三选一增益，每 10 层一位塔主。
- **修炼与经脉**：离线挂机打坐；任督二脉各 8 穴、5 重，越往后冲穴越难。
- **武魂与灵兽**：12 种武魂、5 只灵兽，灵兽会在战斗中出手。
- **装备**：强化到 +15、镶嵌宝石、洗练副属性。
- **师门、押镖、世界首领、论剑**：每日任务、护镖、全天累积血量的世界首领、1000 名的论剑排行榜。
- **称号与转生**：26 个称号，满 60 级可以转生，最多五转，可以改投门派。
- **福利**：签到、在线宝箱，以及一个永远在闪的首充按钮。
- **人情**：善恶值（影响加成、知己和通缉）、四位可结义或结为知己的江湖人物（会随你助战）、最多三名徒弟。
- **百晓生兵器谱**：十大名器，各有独特战斗特效，散落在秘境、世界首领、武林大会、赌坊、通天塔等处。
- **武林大会**：每周一届十六人淘汰赛。
- **秘境探险**：八关随机选门的迷宫，最深处有守护者。
- **生活**：采药挖矿、炼丹（永久属性、临时增益、易容）、锻造装备。
- **赌坊**：猜大小、斗蛐蛐、划拳。
- **手动出招**：打首领、论剑、武林大会等重要战斗时，每回合自己选招式。
- **一键操作**：一键日常、扫荡×10、一键冲穴、一键修炼、一键强化、一键合成与镶嵌、一键论剑、押镖一键走完、世界首领一键打完、通天塔快速连闯，省去反复点击。

## 存档

进度自动保存在浏览器的 localStorage 里。换浏览器或设备之前，在「人物」页导出存档码，到新地方再导入。

## 本地运行

下载 `index.html`，用浏览器打开即可。
