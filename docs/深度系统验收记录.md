固定种子模拟使用当前默认档案、真实战斗与路线规则：3传承×7章节×11模式=231组合，全部合法终止，145通关/86战败。各局包含存档边界校验；模拟采用固定决策，不代表最终平衡或所有玩家胜率。已有高级章节仍需要养成/调整配装。

## 执行中的取舍（Rulings I made）

1. 根据用户“全部、自动、并行”的授权直接落实约定范围，开放配置供后续修改；代价是大量原创数值仍需继续调平衡。
2. 子代理按不重叠文件并行，主代理统一整合、提交与独立审查；代价是共享接口必须集中验证。
3. 复用已经运行的专用功能分支和工作目录，保留原版与用户存档；代价是没有第二份隔离磁盘检出，依靠文件分工与Git提交恢复。
4. 真实Node本机服务落实账号/帮会/PvP，不擅自开通收费公网服务；代价是跨设备使用需要后续托管配置。
