# 七派江湖 · 深度系统与联机版

本批将约定的八组扩展接入独立示范版 `demo/`。根目录原版 `index.html`、原版存档和之前的示范旅程继续保留。新玩法使用原创代码、文字、图标、场景与音效；并未复制参考游戏的素材或源码。

## 启动和继续旅程

需要 Node.js 22 或更新，无 npm 依赖。终端进入解压后的仓库，执行 `node server/start.mjs`；macOS 可运行 `start-demo.command`。打开显示的 `http://127.0.0.1:8768/demo/`。若端口被占用，先关闭旧预览进程，或设置 `PORT=8769 node server/start.mjs` 后使用新地址。浏览器存档按来源隔离：localhost、127.0.0.1、不同端口、不同浏览器之间不会自动共享。

仅用 Python 静态服务也能玩离线系统，但账号、帮会与真人对战需要 Node 服务。直接双击 HTML 只适用于根目录原版。

进入战斗和下一回合都会自动掷出五骰；选中要换的骰子，再点重掷；每回合两次，未选中者保留，固定骰不能换。出招仍由你决定，先看完整推演和敌人意图。按 1–5 选骰、R 重掷、空格执行当前主操作。门庭可继续已经保存的旅程；重新出征会结算旧旅程的放弃状态；也可在出征页点击「放弃已保存旅途」，扣除已用行囊后清除该示范存档，不发放奖励。

## 战斗体验升级

顶部「演出×1 / 演出×2」切换播放速度，可在招式演出中操作，并单独保存为本机设置。减少动态效果仍然有效，倍速不会开启震屏或闪光。

出招时战场下方显示当前招式进度，点击「跳过本轮演出」可立即看完整结算；跳过仍扣除本轮真实消耗、结算一次伤害与奖励，再自动掷出下一回合骰子，不会自动连续出招。演出中暂离或关闭页面仍保留出招前的决策存档。

骰子自动掷出或重掷时有短暂落定动画与音效。只重掷已选骰子，连锁装饰可带动相邻骰；本轮固定骰仍不能换。减少动态设置下不播放落定动画。

结算后的「上一回合战报」可点击标题展开，也可聚焦标题后用空格或回车操作。战报显示当回合骰面/判型、实际扣除敌方气血的总伤害、击败数量、自己气血与护盾的起止值，以及按发生顺序排列的招式。它是已发生的结果，与当前回合推演分别阅读。战报仅保留在当前打开的页面中，回门庭、继续存档或刷新后重新开始记录。

## 装备、词条与预设

品质工坊中，当前装备的详细卡默认展开，其余点击名称展开。品质默认最高三阶，逐阶提高基础效果并解锁被动。生成随机词条后，可逐条锁定，再生成三组完整候选。支付洗练费用只生成候选，接受后才替换；取消会保留原属性，费用不会返还。锁定条目会原样保留在所有候选中；每次锁定与带锁洗练有独立成本。全部词条都锁定时无需洗练。

有未处理候选、词条锁定或装备保护的物品会受到操作限制。重铸前需解锁。遗物分解后不可装配，付费重铸可恢复可用。品质共鸣跨装备、遗物、符文统计，阈值和效果可改。

三套预设保存装备、骰面、门派、武学、遗物、符文、灵兽、武魂与称号选择。预览显示全部效果差异；物品已分解、遗物不可用等情况会禁止载入。预设不会复制物品或回退强化。批量分解按钮处理页面明确列出的全部备用物品；批量融合仅处理有效的同模板备用组合，已装备/受保护/锁定/候选物品自动排除。

普通战斗按概率掉兵装，首领默认保证专属模板。战利品展示可直接收起，不会打断决策。胜利或战败均在旅程结算时接收已获得掉落且只结算一次；主动放弃不接收该旅程掉落。当前旅程的掉落池和词条规则在出发时冻结。

## 七章游历与流派

常规游历的七章拥有独立敌群、布局和事件顺序：竹溪、古寺、雁门、流沙、镜湖、幽陵、天峰。实际场景覆盖竹林、破庙、山门、沙漠、湖桥、墓穴和雪峰。11 种玩法仍保留各自规则；章节独立布局主要在常规游历中体验，其他模式保留其专属路线并叠加章节/模式倍率。

成长显示稀有度，可花本局铜钱有限刷新、有限禁选某分支；高阶路线可有前置条件。先选成长，再选目标骰并确认；内部路线无需选骰。商人售卖局内武学、遗物和骰子装饰；满槽或铜钱不足时按钮禁用，购买后可继续逛，离开才前进。

岔路的高风险选择会改变后续敌人和收益。奇遇可以回复，也可付气血换攻击和收益，代价/诅咒继续影响后续战斗，致死代价不能选择。精英有凶猛、铁甲、汲血等词缀。首领包含破军蓄力、钟盾重建、祭火疗愈召援；半血阶段、架势破招有文字、动作和音效反馈。剑、杖、锤使用不同动作和打击效果。

新手指引可跳过，顶部「指引」可重开。静音和减少动态效果继续有效。

## 日周目标与商店

日课以 UTC 零时换日，周任务以周一 UTC 零时换周；旧的累计进度不会用于无限重复领新周期奖励。高水位时间阻止倒调时钟重复领奖。流动行商按日轮换库存，每批有限购和刷新次数。收藏发现永久记录，分解后仍保留；每章常规游历首通额外奖励自动到账，塔里程碑在完成对应层后手动领取。

## 自己改规则

先到「可视化创作」选保存位置和名称，保存当前配置，再改规则。选择内容分类并点「打开条目」；修改后点「校验并应用此条目」。整份目录会校验，错误不会部分应用。条目 ID、类型等关联标识只读，以免断开档案引用；需要更广调整可导出完整 JSON 修改并重新导入。

可改装备、词条池范围、品质权重、普通/首领掉率、章节敌群与路线、章节奖励、模式、经济、武学、成长前置与权重、奇遇/诅咒、洗练成本、日周任务与行商规则。路线敌人数值是基础值，出发时才叠加章节与模式倍率。

概率表按真实掉落规则计算，包括某品质没有模板时回退到全装备池的概率；词条数受当局配置的最大词条数与可用不同效果键数量共同限制。首领专属表优先，普通品质表不表示专属首领模板概率。

规则模拟运行真实战斗、成长和路线 reducer，使用当前配装和固定种子，每次 1–10 局，提供结果、回合、伤害、剩余气血、掉落数量。模拟采用固定自动决策策略，不消耗档案资源，不是玩家水平或最终平衡保证。`node tools/simulate-expansion.mjs` 可输出三传承 × 七章 × 十一模式的 231 组合报告。

三份快照保存完整内容目录，恢复仍须通过当前档案兼容校验，不会回退玩家资源。完整档案备份需使用「JSON与备份」导出档案。正在进行的旅程继续使用当局快照，新出征才采用修改后的规则。

## 账号、帮会与真人论剑

服务在本机真实运行，密码随机盐 scrypt 摘要保存，登录使用 HttpOnly Cookie。注册登录后不会自动上传或下载你的档案。远端初始为空；点击上传才保存，点击下载才替换本机门庭。并发旧版本写入会返回冲突，不静默覆盖。有未结算旅程时，下载账号档案或导入整份档案会被阻止；先完成旅程或回出征页明确放弃，再替换档案，避免把旅程关联到旧编号。修改内容配置不受此限制，现有旅程继续保留出发快照。导出档案不包含账号密码或会话。

帮会支持创建、加入、离开、查看成员与消息，只有成员可查看会馆与发送消息；重新登录可恢复自己所在会馆。每人一家，会长离开自动交接。

真人论剑必须有两个真实账号，不会补机器人。测试可使用两个浏览器的独立资料或无痕窗口；同一来源的普通标签页共享账号 Cookie。先后点击匹配后，先排队者先手。双方气血100、攻击8、五枚标准骰自动掷、每回合两次重掷；牌型影响伤害，点数1在攻击后提供护盾。每回合120秒，超时或投降会结算。服务端决定骰面、轮次、伤害、版本与胜负，仅对局结算记录进入战绩榜。

默认只在本机使用，跨设备公网访问尚需你选择主机、域名、TLS反向代理及 `QIPAI_PUBLIC_ORIGIN`。未创建收费服务或部署到公网。当前持久化适合单进程的小规模自托管：一个数据目录只允许一个进程，无邮箱找回、管理审核或分布式数据库。账号/帮会/对局数据在被 Git 忽略的 `server/data/`，备份前先停服。重启保留数据和对局，登录会话与等待队列清空。详见 `server/README.md`。
