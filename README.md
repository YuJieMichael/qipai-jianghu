# 七派江湖

一款在浏览器里直接玩的武侠网页游戏，向十几年前的页游《武侠风云》致敬。整个游戏只有一个 `index.html` 文件，不需要安装，不需要服务器。

**在线试玩：** https://yujiemichael.github.io/qipai-jianghu/

## 玩法

- **掷骰战斗**：所有战斗都是掷骰出招。伤害 = 攻击 × 骰型倍率：散招 ×1、一对 ×1.5、两对 ×2、三条 ×3、顺子 ×4、葫芦 ×5、四条 ×7、豹子 ×10。每回合掷 5 颗骰子，可以锁定后重掷（免费 1 次，之后耗内力），也可以一键最优锁骰。
- **走路战斗**：江湖关卡在横版像素场景里打。主角一路往前走，对手迎面走来，停下就地掷骰对打，赢了接着走。七个区域各有自己的景色，人物按门派和兵器画，怪物各有造型。
- **门派骰子**：七派各用一种骰子，点数分布或自带印记不同，比如少林骰两面 4 点、武当骰多一次重掷、唐门骰 1 点带毒 6 点带暴。
- **武学即被动**：门派四招分别在掷出一对、两对、三条、顺子时触发；大骰型会同时触发它包含的小骰型；秘传在四条、豹子时发动。
- **装备**：剑、刀、棍、掌、扇、暗器六种兵器各配合一种骰型；真武、血衣、烈阳、风云四套套装；分解装备得星辰砂，升星最高五星。
- **天机阁抽奖**：用天机令单抽或十连，十连保底珍品，50 抽内必出神品，每天免费一抽，概率在页面公示。只用游戏内货币。
- **骰面刻印**：用武学残页给骰子的某一面刻上剑气、毒、火、寒、暴、吸、回春、金刚、万能等印记，掷出就触发；万能面可以当任意点数。
- **七大门派**：少林、武当、峨嵋、丐帮、明教、唐门、天山，各有 4 招门派武学和 1 招秘传绝学。
- **江湖与主线剧情**：七个区域、七章故事。七次抉择决定侠义、霸道、中庸三种结局。
- **通天塔**：无尽爬塔，层与层之间气血不回满，每 3 层三选一增益，每 10 层一位塔主。
- **修炼与经脉**：离线挂机打坐；任督二脉各 8 穴、5 重，越往后冲穴越难。
- **武魂与灵兽**：12 种武魂、5 只灵兽，灵兽会在战斗中出手。
- **装备**：强化到 +15、镶嵌宝石、洗练副属性。
- **师门、押镖、世界首领、论剑**：每日任务、护镖、全天累积血量的世界首领、1000 名的论剑排行榜。
- **称号**：佩戴一个称号即获得它的属性。
- **福利**：签到、在线宝箱，以及一个永远在闪的首充按钮。
- **人情**：善恶值（影响加成、知己和通缉）、四位可结义或结为知己的江湖人物（会随你助战）、最多三名徒弟。
- **百晓生兵器谱**：十大名器，各有独特战斗特效，散落在秘境、世界首领、武林大会、赌坊、通天塔等处。
- **武林大会**：每周一届十六人淘汰赛。
- **秘境探险**：八关随机选门的迷宫，最深处有守护者。
- **生活**：采药挖矿、炼丹（永久属性、临时增益、易容）、锻造装备。
- **赌坊**：猜大小、斗蛐蛐、划拳。
- **首领机制**：七位江湖首领各有特性（铁布衫、护体罡气、水遁回春、五毒缠身、黄沙遮眼、狂暴、剑意反震），塔主也是。要换武学、名器、知己来应对。
- **每日江湖风云**：每天随机两条江湖动态，比如庙会奇遇翻倍、论剑周声望翻倍、大雨让灼烧减半中毒加倍。
- **偷师**：从奇遇、秘境、悬赏、武林大会、师门学会其他门派的武功，最多同时修习 4 门。
- **悬赏通缉令**：每天三名有名有姓的要犯，按线索猜他藏在哪，猜中才能缉拿。
- **秘境主题与遗物**：古墓、剑冢、毒窟、仙境四种主题；古匣里的遗物三选一，只在当次有效。
- **按进度开放**：新角色一开始只有几个基础玩法，随等级和主线进度逐步解锁。
- **手动掷骰**：勾选后所有战斗都由你锁骰重掷；开着连续挑战时小怪仍自动打。
- **一键操作**：一键日常、扫荡×10、一键冲穴、一键修炼、一键强化、一键合成与镶嵌、一键论剑、押镖一键走完、世界首领一键打完、通天塔快速连闯，省去反复点击。

## 存档

进度自动保存在浏览器的 localStorage 里。换浏览器或设备之前，在「人物」页导出存档码，到新地方再导入。

## 本地运行

下载 `index.html`，用浏览器打开即可。
