# 七派江湖

一款在浏览器里直接玩的武侠网页游戏，向十几年前的页游《武侠风云》致敬。原版集中在 `index.html`，可直接打开；新增示范关卡位于 `demo/`，通过 HTTP 运行。

**在线试玩：** https://yujiemichael.github.io/qipai-jianghu/

## 夜雨竹林 · 破山门示范关卡

首页顶部可进入独立示范关卡，或在本地打开 `/demo/`。这段关卡使用统一起点，包含夜雨竹林、残灯破庙、风起山门三个场景，剑气、毒针、金刚三种传承，五次成长和两阶段山门守将。

每回合掷五骰，点击选择要更换的骰子，只重掷选中的骰子，其余保留；每回合可免费重掷两次，换完后清空选择。三次选择本门成长解锁流派质变。空格执行主操作，1–5 选择要换的骰子，R 重掷；聚焦按钮时保留原生键盘操作。支持静音、减少动态效果和独立的暂离恢复。原版角色存档不受影响。

成长先选武学，再从五颗骰子中选择绑定目标，确认后生效；同门升阶、异门替换，Esc 可返回重选。内部路线无需指定骰子，包含凝锋、回响剑阵、蚀骨余毒、催毒引爆、固若金汤、借力反震六条分支，每条最高二级。待选武学与目标可随存档恢复，旧版示范存档会自动迁移。

战斗前可查看同源结算推演：直接伤害、骰技与毒伤、敌方回应及双方最终气血/护盾。角色采用原创分层剪纸造型与关节动作，三处场景分别绘制，飞剑、附毒、毒蚀、毒爆、护盾与反震各有表现。完整一轮动画按事件权重分配约 2.6 秒，减少动态模式约 1.4 秒。

示范关卡使用 ES modules，须通过 HTTP 运行：

```sh
python3 -m http.server 8765
```

浏览器访问 `http://localhost:8765/demo/`。部署整个仓库到 GitHub Pages 时无需构建。直接双击 HTML 的运行方式仅适用于原版游戏。

验证：`node --test tests/demo-*.test.mjs`；平衡模拟：`node tools/simulate-demo.mjs`。

可使用 `/demo/?seed=2` 重复同一起手，方便对比流派和报告问题。升级版实测、路线模拟与限制见 [验证记录](docs/demo-verification.md)。

## 玩法

- **掷骰战斗**：所有战斗都是掷骰出招。伤害 = 攻击 × 骰型倍率：散招 ×1、一对 ×1.5、两对 ×2、三条 ×3、顺子 ×4、葫芦 ×5、四条 ×7、豹子 ×10。每回合掷 5 颗骰子，可以锁定后重掷（免费 1 次，之后耗内力），也可以一键最优锁骰。
- **闯江湖**（玩法仿《六六英雄》）：每个区域是一整趟路，像素画面里的路一直延伸到远处。点「前进」走到下一处：五处关卡对手和三波流寇（越往后一次来得越多），两处奇遇（宝箱、神秘老者、骰子摊、山泉），一个行脚商人，尽头是首领。
  - 战斗全靠手动：自己掷骰、锁骰、重掷，点选目标后出招；怪物头顶会写出它这一回合要打你多少。空格前进/掷骰/出招，R 重掷，1~5 锁骰。
  - 首领每隔一回合扰乱你的骰子：拦路、镇骰（冻住不能重掷）、浑水（混乱骰有空面）、毒骰、黄沙，各区首领手段不同。
  - 气血整趟不回满。打倒对手攒悟性，攒满就三选一：心法（六六大顺、横扫千军、毒手、天命等十四种）或骰技（剑气、毒针、回春、惊雷、破甲，绑在某一颗骰子上，那颗掷对点数就发动，可练到三重）。铜钱在商人那里换金创药、改点符、顿悟丹。
  - 倒下就结束，已经拿到的奖励不收回。打完首领按剩下的气血评一到三星，第一次拿到两星、三星有奖励。
  - 进度随时存档：关掉页面或点「暂离」，回来在江湖页「继续旅途」。第一次闯关有分步提示。
  - 葫芦以上的大骰型有全屏特效，暴击震屏，音效用 WebAudio 现场合成，手机上挨打会震动，可以在闯关画面顶上关掉。人物按门派和兵器画，怪物各有造型，七个区域各有景色。
- **门派骰子**：七派各用一种骰子，点数分布或自带印记不同，比如少林骰两面 4 点、武当骰多一次重掷、唐门骰 1 点带毒 6 点带暴。
- **武学即被动**：门派四招分别在掷出一对、两对、三条、顺子时触发；大骰型会同时触发它包含的小骰型；秘传在四条、豹子时发动。
- **装备**：剑、刀、棍、掌、扇、暗器六种兵器各配合一种骰型；真武、血衣、烈阳、风云四套套装；分解装备得星辰砂，升星最高五星。
- **天机阁抽奖**：用天机令单抽或十连，十连保底珍品，50 抽内必出神品，每天免费一抽，概率在页面公示。只用游戏内货币。
- **骰面刻印**：用武学残页给骰子的某一面刻上剑气、毒、火、寒、暴、吸、回春、金刚、万能等印记，掷出就触发；万能面可以当任意点数。
- **七大门派**：少林、武当、峨嵋、丐帮、明教、唐门、天山，各有 4 招门派武学和 1 招秘传绝学。
- **江湖与主线剧情**：七个区域、七章故事。七次抉择决定侠义、霸道、中庸三种结局。
- **通天塔**：无尽爬塔，层与层之间气血不回满，每 3 层三选一增益，每 10 层一位塔主。
- **修炼与经脉**：离线挂机打坐；任督二脉各 8 穴、5 重，越往后冲穴越难。
- **武魂与灵兽**：12 种武魂、5 只灵兽，灵兽会在战斗中出手。
- **装备**：强化到 +15、镶嵌宝石、洗练副属性。
- **师门、押镖、世界首领、论剑**：每日任务、护镖、全天累积血量的世界首领、1000 名的论剑排行榜。
- **称号**：佩戴一个称号即获得它的属性。
- **福利**：签到、在线宝箱，以及一个永远在闪的首充按钮。
- **人情**：善恶值（影响加成、知己和通缉）、四位可结义或结为知己的江湖人物（会随你助战）、最多三名徒弟。
- **百晓生兵器谱**：十大名器，各有独特战斗特效，散落在秘境、世界首领、武林大会、赌坊、通天塔等处。
- **武林大会**：每周一届十六人淘汰赛。
- **秘境探险**：八关随机选门的迷宫，最深处有守护者。
- **生活**：采药挖矿、炼丹（永久属性、临时增益、易容）、锻造装备。
- **赌坊**：猜大小、斗蛐蛐、划拳。
- **首领机制**：七位江湖首领各有特性（铁布衫、护体罡气、水遁回春、五毒缠身、黄沙遮眼、狂暴、剑意反震），塔主也是。要换武学、名器、知己来应对。
- **每日江湖风云**：每天随机两条江湖动态，比如庙会奇遇翻倍、论剑周声望翻倍、大雨让灼烧减半中毒加倍。
- **偷师**：从奇遇、秘境、悬赏、武林大会、师门学会其他门派的武功，最多同时修习 4 门。
- **悬赏通缉令**：每天三名有名有姓的要犯，按线索猜他藏在哪，猜中才能缉拿。
- **秘境主题与遗物**：古墓、剑冢、毒窟、仙境四种主题；古匣里的遗物三选一，只在当次有效。
- **按进度开放**：新角色一开始只有几个基础玩法，随等级和主线进度逐步解锁。
- **手动掷骰**：闯江湖本来就是手动；勾选后悬赏、论剑等其他单挑也由你锁骰重掷。
- **一键操作**：一键日常、扫荡×10、一键冲穴、一键修炼、一键强化、一键合成与镶嵌、一键论剑、押镖一键走完、世界首领一键打完、通天塔快速连闯，省去反复点击。

## 存档

进度自动保存在浏览器的 localStorage 里。换浏览器或设备之前，在「人物」页导出存档码，到新地方再导入。

## 本地运行

下载 `index.html`，用浏览器打开即可。
