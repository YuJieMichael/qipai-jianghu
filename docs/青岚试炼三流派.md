# 青岚试炼三流派

2026-10-30。继续扩展已确认的六战竖屏试炼，沿用现有角色、背景和布局。以下是本地原创规则设计，不声称还原参考游戏的全部流派。旧工坊装备仍在原入口。

| 骰技 | 每次投掷的真实效果 | 用途 |
|---|---|---|
| 御剑 | 全体存活敌人受到4×等级伤害 | 清理群怪 |
| 烈火 | 当前选中敌人受到7×等级伤害 | 集中击杀；重掷前可以换目标 |
| 护体 | 获得6×等级护盾，最多60 | 抵挡反击；余盾跨战保留 |

同一种骰技再次选中会升级；绑定另一种则替换原骰技并从1级开始。成长页显示当前技能、真实前后数值及替换提示，选中目标骰并确认后才生效。三种技能各有骰色、效果说明、演出及合成音效。全格挡不会显示负零或伤害抖动，减少动态仍保留读数。

新产生的成长固定三选一：第一战御剑/改面/气血，第二战烈火/护体/气血，第三战御剑/烈火/气血，第四战烈火/护体/气血，第五战御剑/护体/气血。旧存档中已经产生的奖励不重抽，version和存档键不变。为兼容旧合法档案，校验仍接受原范围内的超额护盾；新护体不会把护盾增加到60以上。

修改入口：`demo/renewal/model.mjs` 定义倍率、护盾上限、成长组合及严格校验；`ui.mjs`/`style.css` 定义骰盘与成长说明；`scene.mjs` 定义火弹、护罩和格挡读数；`controller.mjs` 路由现有音效。未新增产品依赖、状态字段或存储服务。

最终451项测试通过。御剑、烈火、护体与混合策略各80局，共320局自动模拟全部通关，这是可达性检查，不代表真人难度。独立审查发现的非字符串技能字段校验已修复并复审。

浏览器通过正常成长绑定护体与烈火：护盾挡住10+6反击后保持120气血；烈火选中右翼弩手后仅其26→19，减少动态下再19→12。360×800、320×568和桌面460×720实际页面已检查，小屏无横向溢出。浏览器QA使用独立本地存档，线上存档保留。
