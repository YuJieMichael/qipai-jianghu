# 双章试炼交付

## 战斗纠正
已确认的原包静态调用链：Dice.clickDice → playerDiceOne → DiceSystem.diceOne，扣重掷次数并更新牌型；剑影CostRollTimes条件给有效剑影骰累积剑气。PlayerAtk之后RearAttack=10才释放剑气，每层经skillTarget[301]转成随机一个存活敌人。基础攻击加入所有参战骰点，重复点数也相加，再乘牌型倍率。证据包括DiceSystem、PlayerOpeSystem、BattleFlowSystem、BuffSystem、SkillSystem、DiceAttrComp和公式表。未运行APK。

当前实现这个已核实子集。固定剑气每层4伤、牌型倍率、烈火和护体、装备数值及本作首领是原创平衡规则；没有把“完整还原六六英雄”作为结论。旧方案把每次投掷都改成全体剑气，现已撤销。

## 四项可玩内容
- 装备：48件原创目录、六槽、每胜一战一件、品质比较、穿戴/卸下、分解、24锻尘铸造至少良品。穿戴在下场生效，当前气血不增加。
- 首领：出招→蓄力→重击，蓄力窗口两对及以上可打断，半血二阶段；头顶显示当前意图。
- 动作：4角色×待机/攻击/受击/倒下，共16张独立姿态；连层剑气按快速连发演出。减少动态可用，旧图集仍可回退。
- 第二章：暮雨山门，六场独立敌群，原创雨夜寺门场景；青岚首领通关永久解锁，可重打。

## 保存与恢复
冒险v1迁移v2保留关卡、血量、骰面、骰技和待选成长，不补播旧伤害。成长档独立于江湖工坊。每场收据幂等；从后续battle/lost状态补领已证明胜利。新旅程用写入日志恢复两个存档键之间的中断，较新同run状态优先，避免回退。
