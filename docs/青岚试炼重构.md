# 青岚试炼：方向纠偏与修改说明

本轮把默认入口重做为独立的六战竖屏试炼。直接打开 `/demo/`；原先的全部装备、天赋、工坊、十一模式仍在 `/demo/workshop.html`。这是一段用于验证画面和操作方向的重新实现，还不能称为《六六英雄》的完整还原。

## 实际改变
- 竖向纵深战场，敌人在上、主角在下；生命贴近角色，骰盘和出招固定在底部。
- 换用原创明亮山径背景和四角色透明图集，增加御剑、受击、死亡和解锁演出。
- 开局一骰；前四战胜利逐步开放其余四槽。点一颗已解锁骰立即花一次机会重掷，绑定剑气的骰子立即向全体敌人发动技能。
- 手动出招根据当前骰型攻击所选目标，存活敌人随后行动；下一回合自动投骰并触发骰技。
- 前五战胜利提供成长：剑气绑定或升级、修改目标骰的一面、气血成长。先选条目，再选目标，确认才生效；最后首领胜利直接结算。
- 新存档与旧工坊分开。浏览器返回、动画输入锁、损坏档案和贴图延迟均有恢复路径。

## 证据边界
官方 App Store 截图支持竖屏布局参考；官方专题描述了重掷剑气、绑定多骰和技能升级。本地 Android 1.4.2 静态核查支持单骰重掷、渐解锁骰位和目标骰成长。没有运行参考 APK，不能据此认定整套实际规则、时序、数值或画面相同。

本试炼的六战编排、自动解锁时机、三类固定成长、数值和美术均为本地设计。尚未把旧工作台的全部装备和养成接入这段试炼；也没有重制参考全部武器流派和完整章节。先用这段连续操作验证方向，后续再围绕实际体验扩展。

## 修改入口
| 文件 | 用途 |
|---|---|
| `demo/renewal/model.mjs` | 生命、攻击、剑气、牌型、敌群、成长和严格存档校验 |
| `demo/renewal/ui.mjs`、`style.css` | 角色血条、骰盘、成长目标、暂停与结果 |
| `demo/renewal/scene.mjs` | 角色位置、图集裁切、逐事件演出、减少动态 |
