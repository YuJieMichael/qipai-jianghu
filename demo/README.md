# 七派江湖 · 全系统本地可改版

入口为仓库中的 `demo/`。这是在夜雨竹林示范基础上扩展的原创离线工坊：先配装、改骰，再以剑气、毒针或金刚传承出征。原版首页 `index.html` 是另一套玩法，存档分开。

## 启动

在源码包根目录运行：

```sh
python3 -m http.server 8768
```

浏览器打开 <http://localhost:8768/demo/>。ES modules 需要 HTTP，不能直接双击 `demo/index.html`。不需构建或安装依赖；停止服务按 Ctrl+C。

## 先玩一局

1. 向下滚动到「江湖门庭」，查看兵装、骰匣、武学和奇珍。
2. 「出征」选择传承、玩法和章节，点击「按当前配装出征」。
3. 开战和下一回合自动掷骰；点击需要更换的骰子，再点「重掷」。未选中的保留。
4. 选敌人、看完整推演，自己点击「出招」。自动掷骰不等于自动攻击。
5. 成长时先选武学，再选绑定骰并确认；路线精进可直接确认。Esc 返回重选。

快捷键：1–5 选择要换的骰子，R 重掷，空格执行当前主操作。焦点位于输入框、按钮或下拉框时保留原生键盘行为。顶部可静音、减少动态效果、回门庭或暂离。

| 类别 | 默认目录与能力 |
|---|---|

| 门派与成长 | 7 门派、12 武学（最多装配 4 式）、8 永久天赋；另有局内剑气／毒针／金刚与六条精进分支 |
| 骰匣 | 5 骰各 6 个物理面；7 材质、8 装饰、9 刻印；材质最高 5 级，变纹最多涉及 2 骰 |
| 奇珍 | 8 遗物（最多 3 件）、10 符文（5 槽、3 方案）、洗练／灌注／共鸣；符文「合成」为本地消耗资源升阶 |
| 同伴与修炼 | 5 灵兽（1 只出战）、6 武魂（最多 3 枚）、称号、3 修炼、3 经脉、3 位关系人物与徒弟 |
| 经济与进度 | 行囊药品、固定街市、本地铜钱抽取、3 类采集、4 配方、6 累计任务、3 成就／阶段目标、每日行路礼、离线收益、图鉴、收藏 |

七章常规路线复用夜雨竹林、残灯破庙、风起山门的三景九节点模板，调整生命／攻击倍率和奖励；不是七组全新场景。其他模式为原创离线路线。本地论剑不匹配真人，本地世界首领的生命仅在这台浏览器里累计。

剑强化顺子；法杖在两对及以上对存活敌人群攻；锤在三条及以上增加护盾并破势。门派切换会把五骰点数重置为本门默认面，之后可在骰匣重新修改。

## 存档、换装与结算

- 兵装、天赋、骰匣、内容配置在**新出征**时生成快照。回门庭改装后继续旧旅程，旧局保持原配装与路线。
- 「门庭」会保留当前旅程；「继续已保存旅途」恢复它。开始新出征或再入江湖会放弃未完成旧局：扣已用药品，不给放弃奖励。
- 药品先消耗本局行囊，胜负或放弃结算时才扣／合并门庭库存。局内购买的药品也随最终行囊结算。
- 正常门庭出征使用递增数字 `runId`；档案记录已结算编号，防止重复恢复或渲染再次领奖。不要手改这些编号。
- 三星章节才可扫荡。默认三星条件为通关、剩余气血至少 40%、累计交锋不超过 18 回合；参数可改。
- 离线所得按本机时间、完整小时领取，默认封顶 12 小时；时间倒退不产生收益。任务累计奖励一次领取，不实现参考游戏完整周任务循环。

自动存档使用同一浏览器、同一地址和端口的 localStorage。原版键 `qipai-jianghu-v1` 保留；本版档案键为 `qipai-bamboo-profile-v1`，旅程键为 `qipai-bamboo-demo-v1`，设置另存。旧示范旅程会校验并迁移到内部 v3。

## 不改代码也能改内容

1. 进入「修改工具」，先点「将档案写入文本」，复制整个文本框保存为 `档案备份.json`。
2. 点「将内容配置写入文本」，复制整个文本框保存为 `内容备份.json`。导出写入文本框，不会自动下载文件。
3. 在完整内容 JSON 中改显示 `name`、已有 `effects` 数字、`cost`／`reward`、章节 `hpScale`／`attackScale`、模式 `turnLimit` 或 `economy.offlineHours`。
4. 粘贴完整 JSON，点「校验并应用内容」。查看反馈；失败时旧配置保留。
5. 新出征检查变化。当前旅程快照不会因导入而改变。

`turnLimit` 必须是 1..1000 整数；`offlineHours` 默认 12，可设为 1..100 整数。资源成本／奖励用非负整数，倍率为正数。保持 `version: 1`、现有 ID、引用和固定枚举；特别不要增删槽位、材质、装饰、刻印、模式，或自造武器种类／触发关键字。改说明文字不会改变固定材质或装饰的程序行为。

内容 JSON 是规则目录；档案 JSON 是个人资源、装备实例、等级、领奖记录及内容覆盖。两者不能互换。档案导入按钮为「校验并导入档案」；档案导出不包含进行中的旅程，不能代替旅程备份。需要恢复规则时使用「恢复默认内容配置」，个人资源不会随之重置；档案还引用自订条目时会拒绝不兼容恢复。「领取测试补给」用于创作试配。

## 源码导航

| 文件 | 修改用途 |
|---|---|
| `content.mjs` | 默认目录、经济／战斗数值和 `validateContent` |
| `profile.mjs` | 档案动作、成本／奖励、配装聚合、一次结算、档案校验 |
| `adventures.mjs` | 11 模式路线、倍率快照、行囊药品 |
| `config.mjs` | 三景九节点基础关卡、敌人和局内平衡 |
| `model.mjs`、`combat.mjs`、`journey.mjs` | 骰面／重掷、伤害与同源预览、成长／事件／关卡流程 |
| `main.mjs`、`storage.mjs` | 控制器、自动初掷、继续／换局、旅程保存与迁移 |
| `hub-ui.mjs`、`ui.mjs`、`style.css` | 门庭表单、战斗 HUD、布局与样式 |
| `scene.mjs`、`actors.mjs`、`choreography.mjs`、`audio.mjs` | 场景、角色、动作节奏、音效 |

源码校验入口为仓库根目录的 `node --test tests/demo-*.test.mjs`；本说明不声明测试数量或发布提交。设计依据见 `docs/superpowers/specs/2026-10-29-full-workshop-design.md`。

## 参考边界

参考拆解整理了 34 类静态系统证据，区分确证、推断和未知；没有解出参考的全部配置表，没有执行参考 APK，也没有复制参考代码或美术。装备、套装、天赋、路线与数值是本项目的原创离线接入，部分采用简化规则。真实联机、服务器支付／广告、账号同步、真人社交和全球排名未接入；这不是完整同款商业游戏，也不表示参考全部系统已复刻。
